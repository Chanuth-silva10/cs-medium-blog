# CS React Vite Starter
A minimal React 19, TypeScript and Vite project built from scratch, with hot reload, tests (Vitest and Testing Library) and linting (ESLint). Part of the DevCraft series by CS Solution (Chapter 35).
## Requirements
Node.js 22 (see `.nvmrc`) and npm.
## Run
```bash
npm install
npm run dev
```
Open `http://localhost:3000`.
## Scripts
| Command | What it does |
| --- | --- |
| `npm run dev` | Starts the dev server with hot reload |
| `npm run build` | Type-checks, then builds into `dist/` |
| `npm run preview` | Serves the production build locally |
| `npm test` | Runs the tests once |
| `npm run lint` | Lints `src/` |
