# CS Java Starter

A minimal Java 21 + Maven starter with SLF4J/Logback logging and Jackson JSON, packaged into an executable uber-jar with the Maven Shade plugin. Part of the DevCraft series by CS Solution.

## Requirements

- JDK 21+
- Maven 3.9+

## Build and run

```bash
mvn package
java -jar target/cs-java-starter.jar
```
